# Sales & Revenue Analysis Dashboard

This project is built using Power BI.

## Features:
- KPI tracking (Sales, Profit, Quantity)
- Sales trend analysis
- Product performance analysis
- Category-wise sales distribution
- Interactive slicers (Date, Category, Product)

## Tools Used:
- Power BI

## Insights:
- Sales show an increasing trend over time
- Top products contribute most revenue
- Electronics category dominates sales
- Profit varies across products
